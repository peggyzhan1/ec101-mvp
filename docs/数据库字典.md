# 数据库字典

CORE 表保存导入快照、客户、商品、订单、活动、核销与履约；RESULT 表保存 `calculation_run`、活动费用汇总、优惠券费用汇总、释放候选与质量提示。

`coupon_fee_summary` 以券配置聚合。能唯一对应券配置时记录其 ID；无法唯一对应时使用 `NULL` 配置桶。汇总始终区分总核销、已关联、可释放与未关联金额。

历史 DDL 中若存在 `entitlement_check` 或理论字段，仅为兼容性保留，不参与运行时核算、接口或前端展示。

## 客户费用确认域

费用确认以“费用周期 + 太古客户编号”为唯一对账粒度。`fee_recipient.expected_amount` 是应发金额的唯一来源；问卷不关联第三方订单、销售凭证、券或具体费用项目。

### 9 张表

| 表 | 用途 | 主键与业务键 | 主要状态 |
| --- | --- | --- | --- |
| `master_sync_batch` | 记录一次数采通客资同步 | PK `master_sync_batch_id` | `running` / `success` / `failed` |
| `taikoo_customer_snapshot` | 保存该同步批次的太古客资快照 | PK `taikoo_customer_snapshot_id`；UK `master_sync_batch_id + sap_customer_primary_key` | 无 |
| `platform_customer_identity` | 保存第三方平台实际出现过的稳定客户身份 | PK `platform_customer_identity_id`；UK `dealer_platform_id + platform_customer_no` | `active` / `inactive` |
| `customer_mapping_snapshot` | 保存太古客户与第三方客户的映射快照 | PK `customer_mapping_snapshot_id`；UK `master_sync_batch_id + source_mapping_id` | 来源状态保存在 `match_status` |
| `fee_cycle` | 定义费用周期 | PK `fee_cycle_id`；UK `fee_cycle_code` | `draft` / `imported` / `executing` / `confirming` / `closed` |
| `fee_recipient` | 保存客户周期级应发汇总 | PK `fee_recipient_id`；UK `fee_cycle_id + sap_customer_code` | `mapping_status`: `pending` / `matched` / `unmatched` / `ambiguous`；`handoff_status`: `pending` / `exported` / `configured` |
| `fee_cycle_activity` | 记录费用周期与第三方活动的追溯关系 | PK `fee_cycle_activity_id`；UK `fee_cycle_id + activity_id` | 无 |
| `survey_import_batch` | 记录一次问卷答卷文件导入 | PK `survey_import_batch_id`；UK `fee_cycle_id + source_file_sha256` | `imported` / `failed` |
| `survey_response` | 保存问卷原始答卷历史 | PK `survey_response_id`；UK `response_fingerprint`，以及 `survey_import_batch_id + raw_sequence_no` | `received_answer`: `received` / `not_received`；`match_status`: `matched` / `not_in_recipient_list` / `invalid` |

### 2 个视图

| 视图 | 规则 |
| --- | --- |
| `v_effective_survey_response` | 每个“费用周期 + 太古客户编号”取提交时间最新的有效答卷；历史有效答案不一致时标记 `has_conflict = 1`。 |
| `v_fee_confirmation_reconciliation` | 从 `fee_recipient` 左连接有效答卷，因此未填写问卷的应发客户仍保留；输出 `未提交`、`答卷冲突`、`已确认收到`、`确认未收到` 或 `答卷无效`。 |

手机号只保存在 `survey_response.respondent_mobile` 中用于受限核验，不通过列表、概览或异常接口返回。
